\## 🛠️ Cómo Ejecutar el Proyecto

1\. Clonar o descargar este repositorio.

2\. Abrir el proyecto en \*\*Unity 6 (o versión LTS)\*\*.

3\. Cargar la escena `Assets/Scenes/SampleScene.unity` y presionar \*\*Play\*\*.
